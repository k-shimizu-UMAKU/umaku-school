ウマクスクール設立準備委員会
利用会員規約

第１章 総則

（名称）

本クラブは「ウマクスクール設立準備委員会」と称する。

（所在地）

本クラブの所在地は、〒590-0951 大阪府堺市堺区市之町西３丁１−１４とする。

（目的）

本クラブは、地域住民の健康増進、体力向上、スポーツを通じた交流促進を図り、豊かな地域社会の形成に寄与することを目的とする。

（事業）

本クラブは、前条の目的を達成するために、次の事業を行う。

  1. 各種スポーツ教室・イベントの開催
  2. 地域住民へのスポーツ機会の提供
  3. 指導者の育成
  4. 他団体との交流
  5. その他、本クラブの目的達成に必要な事業

（会員）

  1. 本クラブの会員は、次のとおりとする。
    • 正会員：本クラブの活動に定期的に参加する個人
    • 賛助会員：本クラブの活動を賛助する個人または団体
  2. 会員資格
    • 正会員：本クラブの目的に賛同し、所定の手続きを経て入会を申し込んだ個人とする。
    • 賛助会員：本クラブの目的に賛同し、本クラブの活動を賛助するために入会を申し込んだ個人または団体とする。
  3. 入会：本クラブに入会しようとする者は、所定の入会申込書を提出し、本クラブの承認を得なければならない。
  4. 退会：会員は、退会を希望する月の前月の15日までに、その旨を本クラブに届け出て、承認を得なければならない。

第２章 組織

（会員）

  1. 会員は、本クラブの活動に参加し、本クラブの事業の推進に協力する。
  2. 会員は、別に定める会費を納入する義務を負う。
  3. 会員は、本クラブの規約および総会の決議を遵守しなければならない。

（役員）

  1. 本クラブに次の役員を置く。
    • 代表 １名
    • 常任理事 ２名
    • 理事 ２名
  2. 役員の選任：役員は、総会において選任する。
  3. 役員の解任：役員は、総会の決議によって解任することができる。
  4. 役員の任期：役員の任期は、１年とする。ただし、再任を妨げない。
  5. 役員の職務
    • 代表は、本クラブを代表し、会務を総理する。
    • 常任理事は、代表理事を補佐し、理事会を構成し、本クラブの業務を執行する。
    • 理事は、理事会を構成し、本クラブの業務を執行する。

（総会）

  1. 総会は、本クラブの最高意思決定機関とする。
  2. 総会の構成：総会は、正会員をもって構成する。
  3. 総会の権限
    • 本クラブの予算および事業計画の決定
    • 本クラブの規約の変更
    • 役員の選任および解任
    • その他、本クラブの運営に関する重要事項の決定
  4. 総会の開催
    • 定時総会は、毎月第3週に開催する。
    • 臨時総会は、必要に応じて開催する。
  5. 総会の議決方法：総会の議決は、出席した正会員の過半数をもって決する。

（理事会）

  1. 理事会は、本クラブの日常的な運営に関する意思決定機関とする。
  2. 理事会の構成：理事会は、代表、副代表および理事をもって構成する。
  3. 理事会の権限
    • 総会から委任された事項の決定
    • 本クラブの業務執行に関する事項の決定
    • その他、本クラブの運営に関する事項の決定
  4. 理事会の開催：理事会は、必要に応じて開催する。
  5. 理事会の議決方法：理事会の議決は、出席した理事の過半数をもって決する。

（事務局）

  1. 本クラブの事務を処理するため、事務局を設置する。
  2. 事務局の組織および職務については、別に定める。

第３章 会計

（経費）

本クラブの運営に必要な経費は、会費、事業収入、寄付金その他の収入をもって充てる。

（会費）

  1. 会員は、本クラブの活動に必要な会費を納入しなければならない。
  2. 会費は、種目別の入会申込書に定める額とする。
  3. 会費の種類は、次のとおりとする。
    • 初回登録費：種目別の入会申込書に定める額とし、スポーツ傷害保険料を含むものとする。
    • 体験費用：種目別の入会申込書に定める額とし、単発での参加の場合に適用する。
  4. 会費の納入方法
    • 初回登録費は、入会時に納入するものとする。
    • 体験費用は、参加時に納入するものとする。
    • 一度納入した会費は、いかなる理由があっても返還しない。

（会計年度）

本クラブの会計年度は、毎年4月1日から3月30日までとする。

（会計処理）

  1. 本クラブの会計処理は、適正に行うものとする。
  2. 本クラブの会計報告は、毎年、総会において行うものとする。
  3. 本クラブの会計監査は、監事が行うものとする。

第４章 その他

（規約の変更）

本規約の変更は、総会の議決を経なければならない。

（解散）

  1. 本クラブは、次の事由により解散する。
    • 総会の議決
    • その他、本クラブの目的を達成することが不可能となった場合
  2. 本クラブの解散時の残余財産は、総会の議決を経て、本クラブの目的に類似の目的を有する他の団体に寄付するものとする。

（個人情報保護）

本クラブは、会員の個人情報の保護に関する法律および関連法令を遵守し、会員の個人情報の適切な管理に努める。

（免責事項）

  1. 本クラブにおける盗難、障害、往復中、その他の事故について、本クラブは一切の賠償責任を負わない。
  2. 活動中における盗難、傷害、死亡等の事故に対する補償は、本クラブが定めるスポーツ傷害保険に定められた範囲とし、本クラブおよび指導者はそれ以上の責任は負わない。
  3. ホップ会員の活動中における傷害等については、応急処置は行うが、本クラブおよび指導者はそれ以降の責任は負わない。（盗難、傷害、死亡等の事故含む）

（規約の改正）

本規約の改正には理事会の議決を経なければならない。

（附則）

本規約は、2026年3月1日から施行する。
